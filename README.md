# 🎯 CS2 Clips Studio & Auto-Cutter (TikTok / Shorts / Reels)

Повністю автономна студія та пайплайн для нарізки CS2 гайдів (розкиди, фішки, піксель-бусти, ванвеї) на готові вертикальні ролики з промо-вставками рулеток.

**Все 100% безкоштовно та локально:** жодних платних API, транскрибація через локальний Whisper, контекстний аналіз на чистому Python, опційний локальний LLM через Ollama.

## Twitch Studio

Локальная студия для англоязычных игровых VOD с русским дубляжом и ручным экспортом. Для запуска нужны Python 3.12 и FFmpeg с фильтром `ass`. На macOS можно использовать Homebrew или указать установленный Python через `TWITCH_PYTHON`.

Скопируйте `.env.example` в `.env` и укажите `RIVER_API_KEY` и `FISH_API_KEY`. Студия автоматически выбирает River, если задан ключ River. Модель по умолчанию — NVIDIA Nemotron 3.5 Super VL. Её можно изменить через `TWITCH_RIVER_MODEL`. Для нативного видеоанализа через Google задайте `TWITCH_ANALYSIS_PROVIDER=gemini` и `GEMINI_API_KEY`. [River Inference](https://docs.river.ai/guides/inference/) · [Ключ Fish Audio](https://fish.audio/app/api-keys)

```bash
./run.sh --twitch --open
```

Студия открывается на [127.0.0.1:8765](http://127.0.0.1:8765). После изменения ключей перезапустите приложение. При первом анализе со звуком Whisper скачивает модель `small` и затем использует локальный кеш.

1. Вставьте HTTPS-ссылку на запись Twitch вида `twitch.tv/videos/123456` или загрузите локальное видео. Выберите голоса для стримера и собеседников. Каталог можно открыть из студии, также можно указать ID голоса напрямую и послушать короткую русскую реплику.
2. При необходимости загрузите рекламное видео с собственной звуковой дорожкой. Проверьте оценку стоимости и нажмите «Найти моменты». River получает кадры с таймкодами по всей записи и английскую транскрипцию от локального Whisper. При повторной проверке частота кадров увеличивается с 2 до 3 кадров в секунду. В режиме Gemini облако получает видео со звуком. Fish Audio получает русский текст для дубляжа. Сумма приблизительная и зависит от числа повторных просмотров и тарифа. Синтез Fish Audio учитывается отдельно. [Поддержка изображений River](https://docs.river.ai/guides/inference-images/) · [Тарифы River](https://docs.river.ai/guides/inference-models/)
3. Проверьте подобранные фрагменты, выберите нужные клипы, поправьте начало, конец или область вебки. Нажмите «Подготовить перевод». Русские реплики, роли и время речи можно исправить до синтеза. Если нет подходящей точки для рекламы, откройте исходный плеер и выберите паузу вручную.
4. Нажмите «Собрать предпросмотр». В итоговом монтаже основной стрим останавливается на время рекламного ролика. После него игровой кадр, звук и субтитры продолжаются по той же шкале времени. Прослушайте микс, затем нажмите «Экспортировать клипы».
5. «Открыть папку» показывает готовые MP4 1080×1920 в `output_clips/twitch-<id>/`. При сбое выберите задачу в боковом меню и нажмите «Повторить этап». Исходники, черновики и кеш лежат в `temp/twitch/`.

Для прямой трансляции вставьте ссылку на канал, например `https://www.twitch.tv/caseoh_`. Запись начинается с момента подключения. Студия проверяет перекрывающиеся окна во время эфира, учитывает всплески звука и активность разных зрителей в доступном чате. Подборки появляются в задаче эфира. Нажмите «Завершить наблюдение», чтобы обработать остаток. Пока идёт наблюдение, окно приложения можно свернуть. Выбранный провайдер анализа оплачивается также во время эфира.

При отборе из большой записи студия сравнивает кандидатов между собой. По ссылке на VOD она также ищет зрительские клипы Twitch с той же записью и перепроверяет до десяти разных популярных эпизодов. Для длинных записей и Twitch VOD студия берёт контекст до и после события, затем проверяет хук и развязку на готовых границах. Если сильных нарезок мало, она перепроверяет кандидатов из других частей записи. Кнопка «Повторить поиск в новой задаче» использует уже скачанный файл и кеш анализа.

У старого CLI и TUI прежний вход через `run.sh`. Для локальной проверки нового режима выполните `.venv-twitch/bin/python -m unittest discover -s tests -v`. Тесты используют FFmpeg и имитируют ответы облачных сервисов. Для оценки качества отбора разметьте пиковые моменты на нескольких игровых VOD и сравните выдачу с прежним речевым отбором.

## 🔁 Невидима унікалізація (анти-дедуп TikTok)

Програма робить кожен кліп **унікальним для алгоритмів, але ідентичним для ока**. Кожен рендер має ВИПАДКОВІ параметри — повторна обробка того ж вихідника дає нові файли:

* мікрокроп 2-5px з країв (після скейлу невидимо) + часовий шум силою 1-2 (змінює кожен піксель → новий перцептивний хеш)
* мікрозсув відтінку (±0.8°) та гамми (±1%)
* випадкове прискорення 1.03-1.05x + випадковий зсув старту + обрізання хвоста 0-0.12с (унікальна тривалість)
* нечутний ультразвуковий тон 16-19kHz @ ~-48dB (ламає аудіо-відбиток)
* випадкові GOP / CQ / бітрейт (±12%)

Замірено на реальному рендері: два виводи того ж кліпу — різні SHA, різні тривалості (29.37с vs 29.50с), різні розміри, **різні перцептивні хеші** (dHash hamming 5/64) при середній піксельній різниці 3/255 (1.2%, оком не видно).

Налаштування: `config.yaml → video.uniquize` (можна вимкнути `enabled: false`).

## ✨ Покращення картинки та звуку (beautify)

* плавніший розмитий фон (проміжна роздільна здатність 270x480 → lanczos)
* легка чіткість геймплею (unsharp 0.35) + делікатна вінєтка
* нові стилі субтитрів: `box` (білий на чорній плашці, TikTok-стиль, за замовчуванням), `classic` (жовтий), `outline`
* аудіо-прибирка голосу: highpass 70Hz (прибирає гул) + м'яка компресія (панчіше) перед loudnorm
* **виправлено розсинхрон субтитрів:** раніше таймінги не масштабувались під прискорення 1.04x і до кінця кліпу відставали на ~1.5с; тепер діляться на фактичний speed кліпу

## 🎯 Якісніша нарізка (семантичні юніти + sentence snapping)

Кліпи складаються **з цілих семантичних юнітів**, а не речень. Юніт — це завершена історія, довша за одне речення: *фішка* (порада → як зробити → результат), *міф* (теза → перевірка → **вердикт**), *правило* (правило → пояснення → приклад). Жодних «обрубків»:

1. **Qwen працює з пронумерованим транскриптом**: кожне речення Whisper має номер `[N]`. Модель повертає `start_sent`/`end_sent` (номера речень) + ехо перших/останніх слів — код звіряє ехо з транскриптом і виправляє збій нумерації. Галюцинація секунд зникла в принципі.
2. **Семантичні юніти**: Qwen маркує кліп `unit_type` (`myth`/`tip`/`rule`). Для міфів код **гарантовано підтягує вердикт** («оказалось», «оценка фейк», «в сухом остатке», «вердикт», «итог») у кліп — навіть якщо модель обрізала вікно раніше.
3. **Довгий міф = серія частин**: юніт до стелі виходить ціликом; довший — ділеться на Ч.1 (кліфгенгер: питання/найцікавіше місце) + Ч.2/Ч.3 з ВЕРДИКТОМ в останній частині. Хуки частин брендуються: «ФЕЙК ИЛИ НЕТ? Ч.1» → «МИФ УНИЧТОЖЕН В CS2! Ч.2».
3a. **Новинні юніти**: для новинних відео переходи («наступна новина», «переходим до новин», «також повідомляють») стають межами — кліп = одна новина від заголовка до кінця, ніхто не стрибає між новинами. Короткі новини (< мінімуму) автоматично склеюються в дайджест до потрібної довжини.
3b. **Питання не відриваються від відповідей**: кліп не може закінчуватись на питанні без відповіді (єдиний виняток — навмисний кліфгенгер Ч.1 міфа), і питання-старт мусить мати продовження.
4. **Whisper Sentence Snapping**: межі кліпів чіпляються за крапки/знаки речень у word-таймстампах (`sentence_snap: true`); хвіст не може висіти на сполучнику («і», «але», «що», «тому що») — дорощується або кліп відкидається.
5. **Локальна детекція юнітів** (регулярки по реальних фразах жанру) працює у фолбеці без LLM і всередині задовгих вікон.
6. **Довжину диктує контекст**: рамки жорсткі — **не коротше 30с і не довше 2 хвилин** — усе інше вирішує семантика (щільний 35-секундний лайфхак так і вийде, а розгорнута історія з перевіркою міфа — хоч 90с). Налаштовувати довжину не треба.

## 🔥 WOW-CUTTER: ранжований відбір «попадання в точку»

Головний апдейт. Замість одного мега-промпту («знайди вірусні моменти», який 3B-модель вгадує) — конвеєр **«Розмітка → Кандидати → Скоринг → Реранк»**:

0. **Прозорий прогрес**: транскрибація показує відсотки («Транскрибація: 68% (11/16 хв)»), розмітка — батчі («батч 5/23»), pull моделі — відсотки завантаження. Жодних «мовчазних» хвилин.
0a. **Швидкість**: Whisper автоматично стає на CUDA (float16 + батчі, ~4x: 19 хв аудіо за ~37с замість 148с), рендер йде у `video.render_workers` паралельних потоків (NVENC тримає декілька сесій). CUDA-бібліотеки підтягуються самі, будь-яка невдача — м'який відкат на CPU.
1. **Розмітка інтересу** (`pipeline/labeler.py`): транскрипт ріжеться на батчі по ~20 речень; Qwen для кожного речення називає роль (`hook/setup/action/result/verdict/filler/offtopic`) і цікавість 0–10 — просте завдання, яке модель тягне стабільно. Карта кешується в `temp/` — повторні запуски миттєві.
2. **Кандидати + детермінований скоринг** (`pipeline/ranker.py`): генеруються **всі** валідні вікна 15–28с (сотні) з гарантіями юнітів, і кожен миттєво скориться без LLM: `Hook-Open` (25) — захоплення уваги з перших секунд; `Payoff` (25) — вердикт/результат, бонус за останню третину; `Interest` (20); `Динаміка` (10); `Чистота` без філерів (10); `CS2-конкретика` (10). Ваги крутяться в `config.yaml → ranking.weights`.
3. **Qwen-реранк**: топ-20 готових текстів модель порівнює і сортує (це 3B тягне надійно) + пише хуки з контенту. Битий хук замінюється детермінованим.
4. **Cold-open форс**: лід-філери («ну, значит, короче») зрізаються; якщо старт не хуковий — кліп зсувається до найближчого хук-річення в перших 4с.
5. **Анти-дубль**: перетин кандидатів > 40% → лишається найкращий.
6. **Модель**: `qwen2.5:7b` з авто-пулом через `ollama pull` (з прогресом у логах) і відкатом на 3b.

**Інструменти контролю:**
- `python main.py --preview` — таблиця відібраних кліпів з розкладкою балів БЕЗ рендеру. Крутиш ваги — бачиш зміну за секунди.
- `python main.py --review` — огляд у консолі перед рендером.
- **TUI-огляд** (`./tui.sh` → Run Process): після аналізу таблиця кліпів — `SPACE` виключити, `R` перегенерувати хук через LLM, `A` прийняти всі, `ENTER` рендерити вибрані.

Без Ollama весь конвеєр працює на евристичній розмітці — повністю детерміновано.

## 🧠 Контекстний аналіз (нове)

Програма тепер **розуміє контекст відео**, а не просто ріже по паузах:

* **Детекція зміни теми** — порівнює лексику сусідніх вікон мови (Jaccard-когезія) і ставить межі кліпів там, де автор реально переходить до наступного розкиду/фішки, а не там де просто пауза.
* **Викидання реклами та сміття** — сегменти типу «підписуйтесь», «промокод», «ставте лайк», інтро/аутро автоматично вирізаються з нарізки (`drop_sponsor_segments`).
* **Скоринг кліпів 0–10** — кожен кліп оцінюється за 5 компонентами: щільність мови, насиченість CS2-термінами, наявність хуку на початку, чистота (без філерів «еєе», «ну», «типу»), завершеність речень на межах. Слабкі кліпи відсіюються (`min_score`).
* **Контекстні заголовки й описи** — з тексту кліпу витягуються сутності (карта, тип гранати, позиція: «Імбовий смок на Window (Mirage)»), а в опис підставляється реальна хук-фраза з відео.
* **Опційне LLM-підсилення через Ollama** — якщо встановлений локальний (безкоштовний) Ollama, заголовки/описи генерує LLM українською + оцінює віральність кожного кліпу. Немає Ollama — автоматично працюють локальні алгоритми вище.

### Налаштування (`config.yaml` → секція `analysis`)

```yaml
analysis:
  enabled: true
  min_score: 4.0              # відсіювати кліпи зі скором нижче
  max_clips: 0                # 0 = всі; або лишити N найкращих
  drop_sponsor_segments: true # вирізати рекламу/інтро/аутро
  topic_shift_threshold: 0.12 # чутливість зміни теми (менше = більше меж)
  use_llm: true               # авто-детект локального Ollama
```

### Як увімкнути LLM-режим (опційно, безкоштовно)

Ollama — локальний LLM-сервер, працює офлайн. На NixOS:

```bash
nix profile install nixpkgs#ollama
ollama serve &            # або services.ollama.enable = true у configuration.nix
ollama pull qwen2.5:3b    # ~2 ГБ, влазить у 6 ГБ VRAM GTX 1660
```

На звичайному Linux: `curl -fsSL https://ollama.com/install.sh | sh`, далі так само.

Після цього нічого налаштовувати не треба — прога сама побачить Ollama на `localhost:11434` і підключиться (у логу з'явиться `[🧠] ... + локальний LLM`).

Політика заголовків: якщо в кліпі розпізнані фактичні сутності (карта/граната/позиція) — використовується точний контекстний заголовок («Імбовий смок на Window (Mirage)»); LLM-креатив підставляється лише коли сутностей нема. LLM також ставить свій скор віральності 1-10 (потрапляє в JSON як `llm_viral_score`).

**Порада щодо якості:** модель Whisper `small` (замість `base`) дає помітно точнішу транскрибацію → кращі субтитри, заголовки і розпізнавання карт. Ціна — ~3 рази повільніше на CPU (`whisper.model_size: "small"` у конфізі, модель скачається автоматично при першому запуску).

Швидкий тест аналізу без рендеру (транскрипція + скоринг):
```bash
.venv/bin/python temp/test_context_analysis.py input_videos/твоє_відео.mp4
```

Якщо потрібно запустити пайплайн автоматично через крон або n8n без графічного інтерфейсу:
```bash
# Обробити всі відео в черзі + авто-архів:

# Стягнути свіжі відео з донорів і нарізати:

# Вставити промо-ролик рулетки посередині кліпів:
./run.sh --promo assets/promo.mp4
```

---

## 📂 Структура проекту

* `tui.py` — інтерактивний графічний термінал (Textual Dashboard).
* `main.py` — фоновий консольний рушій.
* `input_videos/` — папка для вхідних відео.
* `output_clips/` — готові ролики `.mp4` + файли описів і тегів `.json` для n8n.
* `assets/promo.mp4` — ваше рекламне відео рулетки для Mid-roll вставки.
* `config.yaml` — конфігурація тривалості (40с - 3хв), стилів і швидкості.
