# bin/

Ця папка призначена для статичних бінарників FFmpeg.

## macOS
1. `brew install ffmpeg`  — рекомендований спосіб
2. Або завантаж статичний macOS-білд: https://evermeet.cx/ffmpeg/
   і поклади `ffmpeg` + `ffprobe` сюди (в папку `bin/`)

## Linux
1. `sudo pacman -S ffmpeg`  (Arch/Manjaro)
2. `sudo apt install ffmpeg`  (Ubuntu/Debian)
3. Або поклади статичний білд у цю папку
